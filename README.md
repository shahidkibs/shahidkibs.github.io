# Shahid Kibs portfolio — GitHub Pages

Target URL: https://shahidkibs.github.io/

## Publish
1. Sign in to the GitHub account or organisation named `shahidkibs`.
2. Create or use the repository `shahidkibs.github.io`. Inspect existing files before replacing any content.
3. Place this folder’s contents at the repository root, including `index.html`, `styles.css`, `app.js`, `assets/` and `.nojekyll`.
4. In repository Settings → Pages, select Deploy from a branch, then `main` and `/ (root)`, and Save.
5. Wait for the Pages deployment to succeed and verify the target URL.

Upload the contents, not an extra enclosing folder. Do not set a custom domain or add a CNAME file for this github.io address.
